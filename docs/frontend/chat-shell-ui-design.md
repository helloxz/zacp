# zacp 前端壳层 UI 设计方案（简化版对话布局）

> 状态：设计稿（未实现）  
> 日期：2026-08-04  
> 参考：类 ZCode / AI 编程助手 Web 客户端截图（左侧栏 + 中央对话 + 底部用户区）  
> 目标：界面形态相近，**功能做减法**，先落可复用的布局与信息架构，便于后续会话 / WS 联调。

---

## 1. 背景与目标

### 1.1 产品上下文

**zacp** 是 ACP（Agent Client Protocol）多 Agent Web 网关：Web UI 接入多种 Agent，后端作 ACP Client，经 REST + WebSocket 做会话与流式交互。

前端栈已定（见仓库 `AGENTS.md` / `frontend/README.md`）：

| 项 | 选择 |
|----|------|
| 框架 | Vue 3 + TypeScript + Vite |
| UI | Naive UI（按需引入） |
| 样式 | Tailwind CSS v4 |
| 状态 / 路由 | Pinia + Vue Router |
| 国际化 | vue-i18n（`zh-CN` / `en-US`） |
| 包管理 | Bun only |
| 开发端口 | `0.0.0.0:8681` |

### 1.2 参考界面拆解（参考图）

参考客户端大致分为：

| 区域 | 参考内容 | 简化版是否保留 |
|------|----------|----------------|
| 顶栏 | 返回 / 前进 / 刷新 / 通知 | **弱化或去掉**（Web 用浏览器导航即可） |
| 侧栏顶操作 | 新建任务、搜索 | **仅保留「新建会话」** |
| 侧栏列表 | 项目 / 会话分组 | **改为工作区 + 会话列表**（贴合 zacp 领域） |
| 侧栏底 | 头像、昵称、设置 | **保留** |
| 主区空态 | 问候语 + 大号品牌水印 + 居中输入卡片 | **保留形态**，文案与控件简化 |
| 输入卡片 | 项目/模式、@ 提及、计划模式、模型、发送 | **保留：Agent 选择 + 输入 + 发送**；其余复杂能力不做 |

### 1.3 设计目标

1. **布局相似度**：左侧固定边栏 + 左下用户区 + 中间对话主区，一眼像「现代 AI 对话工作台」。
2. **功能极简**：首期只服务「选 Agent / 建会话 / 发消息 / 看流式回复」闭环（后端能力就绪后再接线）。
3. **可演进**：侧栏、空态、输入条、消息列表拆成独立组件，后续可加搜索、权限弹窗、工具调用卡片等而不推翻壳层。
4. **与现有约定一致**：中英 i18n、Naive 按需、camelCase API、关键逻辑中文注释。

### 1.4 非目标（首期明确不做）

- 定时任务、技能市场、计划模式、画板、子智能体编排
- 复杂「项目树 / SSH 多主机」管理（zacp 用 **Workspace 工作目录** 即可）
- 完整鉴权账号体系（用户区先用本地占位：昵称 + 头像占位）
- 深色主题切换（可预留，默认浅色）
- URL 语言前缀、SEO 多语言路由

## 2. 信息架构（简化）

### 2.1 领域映射（参考 UI → zacp）

| 参考概念 | zacp 概念 | 说明 |
|----------|-----------|------|
| 新建任务 | 新建会话（Session） | 绑定某个 Agent + Workspace |
| 项目 / 仓库 | Workspace | 对应会话工作区 cwd |
| 历史任务列表 | Session 列表 | 按最近活跃排序 |
| 模型选择 | Agent 选择 | `[[agents]]` 配置的 id/name |
| 对话主区 | Chat / Session 详情 | 消息流 + 输入框 |

### 2.2 首期用户路径

```text
打开应用
  → 侧栏可见工作区/会话（可为空）
  → 主区：问候空态 + 居中输入卡片
  → 选择 Agent（及可选工作区）→ 输入 → 发送
  → 进入「会话中」态：消息列表 + 底部输入条
  → 侧栏出现/高亮当前会话
  → 左下角打开设置（语言等）
```

### 2.3 路由（建议）

不使用语言路径前缀（已定）。壳层内以会话为主：

| 路径 | 名称 | 说明 |
|------|------|------|
| `/` | `home` | 默认进入壳层；无 `sessionId` 时主区为空态 |
| `/sessions/:sessionId` | `session` | 主区展示该会话消息 |
| `/settings` | `settings` | **可选**：全页设置；也可仅用侧栏底弹层/抽屉，二选一实现时定 |

**推荐**：设置用 **抽屉 / 弹窗**（从左下齿轮打开），路由保持 `/` 与 `/sessions/:id` 两条主路径，减少「跳出对话」感。设置项少时优先抽屉。

## 3. 整体布局

### 3.1 栅格结构

```text
┌──────────────────────────────────────────────────────────────────┐
│  AppShell（100vh，overflow hidden）                               │
│  ┌─────────────┬────────────────────────────────────────────────┐ │
│  │ Sidebar     │  MainPane                                      │ │
│  │ ~260px      │  flex-1，min-w-0                                │ │
│  │             │  ┌────────────────────────────────────────────┐ │ │
│  │ [新建会话]   │  │  （可选）SessionHeader：标题 / Agent 标签   │ │ │
│  │             │  ├────────────────────────────────────────────┤ │ │
│  │ [会话列表]   │  │  ChatViewport（可滚动）                    │ │ │
│  │  · 会话 A   │  │   - 空态：问候 + 水印 + 居中 ComposerCard  │ │ │
│  │  · 会话 B   │  │   - 有消息：MessageList + 流式尾部         │ │ │
│  │             │  ├────────────────────────────────────────────┤ │ │
│  │             │  │  ComposerBar（有会话时贴底；空态可居中）   │ │ │
│  │             │  └────────────────────────────────────────────┘ │ │
│  │ ─────────   │                                                │ │
│  │ UserFooter  │                                                │ │
│  │ 头像 昵称 ⚙ │                                                │ │
│  └─────────────┴────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────┘
```

### 3.2 尺寸与行为

| 项 | 建议 |
|----|------|
| 侧栏宽度 | 默认 **260px**；可折叠至 **64px**（仅图标，二期）；首期可只做固定宽 |
| 侧栏背景 | 浅灰（如 `slate-50` / `#f5f5f5`），与主区白底区分 |
| 主区背景 | 白或极浅灰，中央留白大 |
| 高度 | 整页 `h-screen`，内部滚动，避免 body 双滚动条 |
| 响应式 | **≥1024px** 完整三区；**&lt;1024px** 侧栏改为抽屉（汉堡按钮），主区全宽。首期可先桌面优先，移动端侧栏抽屉作为明确二期 |

### 3.3 视觉关键词（对齐参考图）

- 大留白、轻边框、圆角卡片（输入区约 `rounded-2xl`）
- 侧栏列表项：**选中浅底 + 圆角**；非选中 hover 轻微底色
- 主区空态：**居中问候标题** + 可选极淡品牌水印（zacp 字母/图形，不抢戏）
- 输入区：白底卡片 + 柔和阴影或细边框，控件紧凑、字号偏小
- 主色：可用 Naive 默认绿作主按钮；避免大面积高饱和色块

## 4. 区域详细设计

### 4.1 侧栏顶部 — 主操作

**首期只放：**

1. **新建会话**  
   - 样式：全宽或接近全宽的次要/主按钮  
   - 行为：清空当前选中会话（或创建 draft session），主区回到空态 Composer；真正落库可在「首次发送」时创建（推荐，减少空会话垃圾）

**明确不做（参考图有、我们砍掉）：**

- 搜索入口  
- 定时任务  
- 技能  

（侧栏顶区保持干净，后续加功能时再扩展 `SidebarActions`。）

### 4.2 侧栏中部 — 列表

**结构建议（两级即可）：**

```text
工作区（可选分组头）
  └─ 会话列表项（标题、相对时间、进行中指示）
```

若首期 Workspace API 已具备：

- 分组标题显示工作区名（路径可截断 tooltip 全路径）
- 其下为该工作区的 sessions

若希望更简单：

- **扁平会话列表**（最近 N 条），工作区仅在新建/发送时选择，列表项副标题显示 workspace 名

**列表项字段（最小）：**

| 字段 | 展示 |
|------|------|
| title | 会话标题；无则「新会话」/ 首条用户消息截断 |
| updatedAt | 相对时间（今天 / 昨天 / N 天前）— 可用简易自写，不必上重库 |
| status | 可选：streaming 时小点或 spinner |
| agentName | 可选副文案 |

**交互：**

- 点击 → 路由 `/sessions/:id`，加载历史消息  
- 当前项高亮  
- 悬停可出「更多」：删除（确认）；重命名二期  

参考图中的「显示更多」、多项目折叠：**首期用「加载更多 / 分页」或一次拉最近 50 条即可**。

### 4.3 侧栏底部 — 用户区（UserFooter）

固定在侧栏底部，与列表滚动分离（`flex`：列表 `flex-1 overflow-auto`，Footer `shrink-0`）。

| 元素 | 行为 |
|------|------|
| 头像 | 圆形占位（首字母或默认图标）；暂无上传 |
| 昵称 | 默认可读配置或本地 `localStorage`（如 `zacp.displayName`，默认 `User` / 本机名占位） |
| 设置按钮 | 打开设置抽屉：语言（已有 i18n）、显示名、后续主题等 |

**不做：** 多账号切换、OAuth（除非产品后续立项）。

### 4.4 主区 — 空态（Empty / Welcome）

当无 `sessionId` 或当前会话无消息时：

1. **可选**：极淡居中水印（品牌）  
2. **问候标题**：按时段变化更佳（早上好 / 下午好 / 晚上好），中英走 i18n  
3. **居中 ComposerCard**（见 4.6）  

对齐参考图的「先聊天再产生会话」心智。

### 4.5 主区 — 会话中（Chat）

| 子区域 | 说明 |
|--------|------|
| SessionHeader（可选） | 会话标题、当前 Agent、连接状态（idle / streaming / error） |
| MessageList | 用户消息右或左对齐二选一（建议：**用户右、助手左** 或 两者都左但样式区分）；支持流式追加最后一条 assistant |
| 滚动 | 新 token / 新消息默认贴底；用户上滚后暂停自动贴底，出现「回到底部」按钮 |

**消息类型（首期 UI 只需展示）：**

- `user` 文本  
- `assistant` 文本（流式）  
- 系统/错误条（红色或 warning 条）  

**二期再做：** 工具调用卡片、权限确认弹窗、代码块增强、附件。

### 4.6 输入区 — Composer

分两种摆放，**同一组件** `Composer`：

| 模式 | 何时 | 布局 |
|------|------|------|
| `card` | 空态 | 主区垂直水平居中，卡片最大宽约 `640–720px` |
| `bar` | 会话中 | 主区底部，最大宽与消息列对齐（如 `max-w-3xl mx-auto`） |

**首期控件（简化）：**

```text
┌─────────────────────────────────────────────────────────┐
│  [Agent ▾]   （可选）[Workspace ▾]                        │
│  ┌─────────────────────────────────────────────────────┐ │
│  │ 多行输入：placeholder 提示「给 Agent 发送消息…」     │ │
│  └─────────────────────────────────────────────────────┘ │
│                              [发送 ↵] 或 流式中 [停止]    │
└─────────────────────────────────────────────────────────┘
```

| 控件 | 说明 |
|------|------|
| Agent 下拉 | 来自 `GET /api/v1/agents`；仅 enabled |
| Workspace 下拉 | 可选；来自 workspaces API；空则用后端 default_cwd |
| 文本框 | textarea，Enter 发送、Shift+Enter 换行（可配置，写入设计约定） |
| 发送 | 非空才可点；发送中禁用或变停止 |
| 停止 | 映射后续 cancel API / WS cancel |

**砍掉的参考能力：** @ 提及文件、计划模式、模型档位「最高」、切换模式快捷键条等。可在 placeholder 用一行小字说明「支持多轮对话」，不必做 chip 工具条。

### 4.7 设置抽屉（SettingsDrawer）

从 UserFooter 齿轮打开：

| 项 | 说明 |
|----|------|
| 语言 | 复用现有 `LocaleSwitch`（浏览器 + localStorage） |
| 显示名 | 本地保存，影响左下昵称 |
| 关于 | 应用名、版本（`import.meta.env` 或写死 0.x） |

## 5. 组件拆分（建议目录）

在现有 `frontend/src` 上扩展（实现阶段）：

```text
src/
├── layouts/
│   └── AppShell.vue          # 侧栏 + 主区骨架
├── components/
│   ├── shell/
│   │   ├── AppSidebar.vue
│   │   ├── SidebarSessionList.vue
│   │   ├── SessionListItem.vue
│   │   ├── UserFooter.vue
│   │   └── SettingsDrawer.vue
│   ├── chat/
│   │   ├── ChatPane.vue        # 空态 / 会话中切换
│   │   ├── WelcomeHero.vue     # 问候 + 水印
│   │   ├── MessageList.vue
│   │   ├── MessageItem.vue
│   │   ├── Composer.vue        # card | bar 两种布局 prop
│   │   └── ScrollToBottom.vue
│   └── LocaleSwitch.vue        # 已有
├── pages/
│   └── ShellPage.vue           # 挂 AppShell；根据 route 渲染 ChatPane
├── stores/
│   ├── app.ts                  # 已有：locale
│   ├── session.ts              # 列表、当前会话、消息（后续）
│   └── agent.ts                # agent 列表缓存（后续）
└── composables/
    ├── useLocaleSwitch.ts      # 已有
    └── useChatScroll.ts        # 贴底策略（后续）
```

**原则：**

- 壳层组件不直接 `fetch` 细节可先 mock；接 API 时进 `stores` / `api`  
- `Composer` 纯展示 + emit（`submit` / `cancel` / `update:agentId`），便于空态与会话中复用

## 6. 状态与数据流（设计级）

### 6.1 客户端状态（Pinia 示意）

```text
app:     locale, displayName
agent:   list[], loading
session: list[], currentId, messagesById, streaming
ui:      sidebarCollapsed, settingsOpen（也可组件本地 ref）
```

### 6.2 与后端的边界（实现时）

| 能力 | 接口方向（已有/规划） | UI 时机 |
|------|----------------------|---------|
| Agent 列表 | `GET /api/v1/agents` | 进入壳层、打开下拉 |
| Workspace | `GET/POST /api/v1/workspaces` | 下拉与分组 |
| 会话 CRUD | `/api/v1/sessions` | 列表、删除、进入详情 |
| 历史消息 | `GET .../messages` | 进入会话 |
| 流式对话 | WebSocket `/api/v1/ws`（规划） | Composer 发送后 |
| 权限 | WS `permission.request` | 二期 Modal |

**首期可先做纯 UI + mock 数据**，布局与动线跑通后再接线。设计文档不绑定具体 JSON 字段版本；字段以 backend model 的 camelCase 为准。

### 6.3 流式 UI 约束

- 热路径：消息列表 **追加 / 改最后一条**，禁止每 token 重建整表  
- 长文：二期再考虑虚拟列表  
- 取消：停止按钮 → 发 cancel，UI 标记 interrupted

## 7. 国际化

- 所有壳层可见字符串走 `vue-i18n`（`zh-CN` / `en-US`）  
- 建议 key 前缀：  
  - `shell.*` 侧栏、用户区  
  - `chat.*` 问候、输入、空态、发送/停止  
  - `settings.*` 设置抽屉  
- Agent 名、会话标题、消息正文：**不翻译**（服务端/用户内容）  
- 相对时间：简单规则中英两套文案即可

## 8. 无障碍与交互细节

| 项 | 约定 |
|----|------|
| 焦点 | 进入空态 / 会话后，输入框 autofocus（尊重减少动效可关） |
| 键盘 | Enter 发送；Shift+Enter 换行；Esc 关闭设置抽屉 |
| 加载 | 侧栏列表 skeleton 或 spinner；发送中按钮 loading |
| 错误 | `n-message` / 内联 error bar，文案 i18n；不暴露本机敏感路径 |
| 空列表 | 侧栏「暂无会话」引导点「新建」 |

## 10. 与当前脚手架的关系

现有 `frontend` 已具备：Vite、Naive 按需、Tailwind、Pinia、Router、i18n、顶栏横向导航页。

**迁移策略（实现时）：**

1. 用 **AppShell 对话布局** 替换当前「顶栏横向菜单 + 居中内容」的 `AppLayout` 作为默认主界面。  
2. 原 `HomePage` / `SessionsPage` 逻辑并入 `ChatPane` + 侧栏，避免双首页。  
3. `LocaleSwitch` 迁入设置抽屉；顶栏语言选择可删或保留极简。  
4. 开发端口、代理、`0.0.0.0` 绑定等工程配置保持不变。

## 11. 设计决策摘要（给实现者）

1. **布局**：左 Sidebar（顶操作 + 中列表 + 底用户）+ 右 Chat 主区。  
2. **功能减法**：只保留新建会话、会话列表、Agent/Workspace 选择、输入发送、设置（语言/昵称）。  
3. **空态优先**：无会话时大留白问候 + 居中 Composer 卡片。  
4. **Composer 一组件两形态**：`card` / `bar`。  
5. **设置**：左下齿轮 → 抽屉，不强制独立路由。  
6. **用户**：本地占位，不做真登录。  
7. **技术**：Vue3 + Naive + Tailwind + Pinia + vue-i18n；组件按上表拆分。  
8. **先 UI 后接线**：P0/P1 mock，再 REST/WS。
